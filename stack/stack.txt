1. Linear data structure operating on LIFO mode
2. Stack top always tracks the topmost element on the stack
3. push operation - add one element to the top of the stack, updates the stack top
4. pop operation - remove and return the top most element on the stack, updates the stack top
5. peek operation - returns the element in stack top without removing it, no update on the stack top
6. is_full operation - checks if the stack is full, can be useful when doing push operation
7. is_empty operation - checks if the stack is empty, can be useful when doing the pop operation

Algo:
====

init()
-------

1. Define an array with STACK_MAX length
2. Define a variable stack_top with -1 initial value

is_empty()
---------------

1. Function returns 0 if stack is empty, otherwise -1
2. check if stack_top is -1
3. if yes, return 0, else -1

is_full()
----------

1. Function returns 0 if stack is full, otherwise -1
2. Check if stack_top is equal to (STACK_MAX -1)
3. If yes, return 0, otherwise -1

push()
----------

1. Function pushes data into stack. Returns 0 if success, otherwise -1
2. Call is_full(). If return is -1 exit from function with -1
3. Increment the stack_top once.
4. Add element into the stack array at stack_top index.

pop()
--------

1. Function remove and return data from stack_top. Returns 0 if success, otherwise -1
2. Call is_empty(), If return is -1 exit from the function with -1.
3. Read the value from stack_top index and assign it to pass by reference parameter.
4. Decrement the stack_top once.

peek()
---------

1. Function reads the data from stack top. Returns 0 if success, otherwise -1.
2. Call is_empty() function, if return value is -1, exit from the function with -1.
3. Read the value from stack_top index and assign it to pass by reference parameter.
